## Follow-up audit round (Claude Code, 3 agents, second pass on this same PR)

A second, independent audit was run against the PR as opened — one agent per: (1) capability-map file citations, (2) deterministic-limits/settings-value accuracy, (3) known-issues citations + overall completeness. Every fact cited in this round was independently spot-checked against live `settings.py`/`execution/risk_gate.py`/the referenced modules before being applied — not taken on the agents' word alone. Findings applied to `docs/AGENTIC_TRADING_SAFETY_FRAMEWORK.md`:

- **Fixed a mis-citation**: "Paper trading book" cited `transactions_store.py` (a closed-trade ledger feeding Kelly sizing), not the actual paper-broker state store, `data/paper_account_store.py` (the default `BROKER_BACKEND="fmp_paper"` engine's virtual cash/positions/orders).
- **Downgraded an overstated status**: "Options Desk Automation (Phases 19-36)" was "Production-ready"; only 0DTE lifecycle management is wired into the daemon's timer loop — `PAPER_OPTIONS_AUTO_EXECUTE_ENABLED`'s exit-management/auto-execution/delta-hedging behaviors have no `main_orchestrator.py`/daemon equivalent (`docs/known_issues/options_lifecycle_daemon_gate_gap_2026_08_22.md`). Now "Partial".
- **Fixed a misattributed mechanism**: the Macro Kill Switch bullet credited `risk_gate.py::macro_kill_switch_check` itself with failing closed on missing FRED data; that logic actually lives in `dto_models.py::MacroEconomicDTO.killSwitch`/`macro_engine.py`, one layer down — `risk_gate.py` only consumes the already-fail-closed flag. Corrected the attribution and folded in the 2026-08 follow-up fix (fabricated-defaults case) the original citation omitted.
- **Fixed an ordering/precision gap**: the deterministic-limits bullet list didn't match `PreTradeRiskGate.run_all()`'s real execution order (Order Rate is deliberately always last, not fifth), and "10 orders per 60 seconds" didn't specify it's a rolling window, not a fixed clock bucket. Also added the sizing-layer `MAX_PORTFOLIO_GROSS` portfolio cap, a real deterministic limit the doc omitted entirely (it isn't inside `risk_gate.py`, so it's called out as a separate, earlier-stage check rather than folded into the risk-gate list).
- **Fixed a mischaracterization**: "State validation" credited `execution/queue_builder.py` with independent outcome-verification logic; it's actually a thin wrapper around the same `PreTradeRiskGate` already covered by "Deterministic limits" — reworded to say so plainly rather than imply a distinct guardrail exists.
- **Closed real completeness gaps** in "Input/Output filtering" (added DLP redaction via `api/_redact.py` and the prompt-registry HMAC-signing/deny-list gate, `docs/known_issues/prompt_registry_unsigned_remote_adoption.md` — a second, directly relevant known-issues doc the original draft never cited), "Model alignment" (replaced generic filler with the concrete `prompt_registry/guardrails.py::validate_prompt()` deny-list/required-marker mechanism), and "Observability" (named the four real per-surface audit stores that exist, while keeping the accurate "not cross-agent-joined" conclusion).
- **Minor precision fixes**: the "Decision journal" and "Opportunity discovery" capability-map rows got clarifying notes (the former isn't part of the decommissioned Streamlit GUI despite its `gui/` path; the latter's skill-path citation now matches the `.claude`-first/`.agents`-parenthetical convention used elsewhere in the doc), and "Runtime settings read/write store" now cites the actual `runtime_flags.py`/`runtime_flags_writer.py` modules instead of bare `settings.py`.
- **Sharpened the Human override and Open-gaps sections** with concrete grounding (the Alpaca/FMP `pending_approval` contrast, the `TestSkillMdInvariantsPinned` pinned test, `api/auth.py`'s shared-secret-not-identity model) rather than leaving them as unattributed generic statements.

No runtime code was touched in either round. The changes have been pushed to update this same PR.

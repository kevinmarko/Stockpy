Forecasting Rebuild F4 Part 1: Archive

This PR executes the first half of the F4 step in the forecasting rebuild plan, archiving subsystems without altering live model behavior:
- **BERT-LLA**: Moved `forecasting/bert_lla.py` to `legacy/`. The live `forecast_errors` ledger never had a single row for `bert_lla`, `lstm_attention`, or `lstm_baseline`.
- **Attention Diagnostic**: Moved `pilots/lstm_diagnostic.py` and its API endpoints to `legacy/`.
- **ASVI Feature Engineering**: Moved `ml/asvi_feature_engineering.py` to `legacy/`.
- **Drift Shrinkage**: Removed `FORECAST_DRIFT_SHRINKAGE` (never enabled live).
- **Sector Config Loader**: Moved `forecasting/sector_configs.json` and its tools to `legacy/`.

### Frozen Inputs & D1=(b) Decision
The `forecasting/sector_configs.json` dictionary is now the frozen constant `SECTOR_FORECAST_CONFIGS_FROZEN` in `forecasting_engine.py`. A frozen-input diff against `origin/main`'s engine ran on the latest 63 symbols from `state_snapshot.json` and moved exactly zero symbols. 
*Note: Freezing this configuration also removed the bug where the loader depended on the process CWD.*
The `_blend_with_skill` preference logic and `cnn_lstm_worker.py::fit_predict_lstm_attention` remain active, pending the F3 naive gate flip (F4 part 2).

### Webapp
- Removed `attention` from `api/metrics_api.py` and `webapp/src/api/types.ts`.
- Removed `AttentionHeatmapStrip` from the Pilots PWA.
- Retired the 5 `BERT_LLA_*` and 2 `SECTOR_FORECAST_CONFIG*` settings from the GUI.
- Tests updated and passed. (Note: losing `SECTOR_FORECAST_CONFIGS` removed the dict-shaped JSON PUT test coverage).

### `.env` Cleanup
The following keys are now ignored and can be deleted from your live `.env`:
`BERT_LLA_ENABLED`, `BERT_LLA_WINDOW_SIZE`, `BERT_LLA_MIN_SENTIMENT_COVERAGE`, `BERT_LLA_BLEND_ENABLED`, `BERT_LLA_ABLATION_ENABLED`, `SECTOR_FORECAST_CONFIG_PATH`, `SECTOR_FORECAST_CONFIGS`

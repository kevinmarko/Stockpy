## Settings census (generated + hand-maintained pair)

`settings_field_census.md`/`.json` are **regenerated by `scripts/measure_settings_census.py --write`**
— do not hand-edit. `settings_partition_notes.md` is hand-written prose triaging a
specific historical census run and relative-links back to the generated file, so all
three stay co-located at `docs/` root rather than moving into `plans/`.

| File | Purpose |
|------|---------|
| [`settings_field_census.md`](settings_field_census.md) | Generated: every `Settings` field, measured usage, classification |
| `settings_field_census.json` | Same data, machine-readable |
| [`settings_partition_notes.md`](settings_partition_notes.md) | Hand-written plain-English triage of a specific census run |

# Robinhood Confirmation Gate is Prose-Only

The `robinhood-execution` skill is the only actor permitted to call the Robinhood Trading MCP write tools. However, the critical safety invariant requiring one explicit human confirmation per placed order is enforced entirely by prose instructions in the `.claude/skills/robinhood-execution/SKILL.md` (or `.agents/skills/robinhood-execution/SKILL.md`) file, not by code or system constraints.

This is a known gap: the platform relies on the LLM adhering to its instructions to present the order to the operator and await explicit confirmation rather than batching orders or proceeding autonomously.

**Why this can't be code-enforced (yet):** unlike the Alpaca/FMP live-execution path (`broker_live_execution_mcp.py` + `execution/live_trade_proposals_store.py`), which has a real server-side `pending_approval` durable state and an atomic claim-for-execution step requiring an authenticated HTTP approval call, the Robinhood order-placement tools (`place_equity_order`, etc.) are exposed by a **third-party MCP server** — not code that lives in this repository. There is no interception point here that could sit between an agent's tool call and Robinhood's own API; the confirmation-gate logic can only live in the instructions the calling agent is told to follow, because this repo has no code path in the loop to enforce it mechanically. Building an equivalent server-side gate would require either Robinhood itself exposing one, or a proxy layer between the agent and the Robinhood MCP that this repo does not currently have and has not built.

**Mitigation:**
A test (`TestSkillMdInvariantsPinned` in `tests/test_robinhood_e2e.py`) has been added to pin the verbatim safety language in the `SKILL.md` file, ensuring that the required instructions cannot be accidentally removed or modified without failing the test suite. This is defense-in-depth against silent prose drift — it is explicitly **not** a substitute for code-level enforcement, since no such enforcement point exists for this particular integration.
